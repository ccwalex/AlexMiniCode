Module metadata is written by the meta_writer pipeline after tracked file changes.
It is stored as JSON sidecars under agent_memory/meta/ and aggregated into
agent_memory/core/metadata.json. Do not embed metadata dictionaries in source files.

python metadata sidecar

{
    "name": "function_or_class_name",
    "type": "function",
    "description": "What this module exports and does.",
    "functions": [
        {
            "name": "function_name",
            "inputs": {
                "arg": "type / description"
            },
            "outputs": "type / description"
        }
    ],
    "path": "code/modules/example.py"
}
